About Extract Pages

Extract Pages copies the page numbers you specify into a new PDF while preserving their sorted order.

How to Use Extract Pages Online

  1. Upload a PDF and note the page count shown.
  2. Enter the pages or ranges you want to keep.
  3. Select Extract Pages.
  4. Open the generated PDF and confirm the selected pages.

100% Client-Side Privacy

Files process in local browser memory via WebAssembly. Your documents are never uploaded to remote servers.

Supported Input

One PDF and page numbers

Output Result

A new PDF containing selected pages

Practical Pro-Tip

Use commas between separate selections and hyphens for ranges.
