Tool Overview & Requirements

Rotate PDF updates page rotation metadata for the selected pages. It supports all, odd, even, or custom page selections.

Input One PDF and page selection
Output A rotated PDF
Requirements One readable PDF is required. Custom selections use page numbers and ranges.

Step-by-Step Instructions

Follow these essential instructions to achieve optimal results when using Rotate PDF:

  1. Upload a PDF.
  2. Choose 90, 180, or 270 degrees.
  3. Choose All pages, Even pages, Odd pages, or Custom pages.
  4. Select Rotate PDF and inspect the page orientation.

Step 2 of 7 File Browser (#fin)

Upload PDF Document

What to do:

Select your PDF document requiring orientation correction.

What you will see:

The document loads and total page count is displayed.

Next:

Choose rotation angle and page targets.

Tip:

Step 3 of 7 Angle Selector (#deg)

Select Rotation Angle

What to do:

Choose the degree of rotation from the dropdown (90° Clockwise, 180° Flip, or 270° Counter-clockwise).

What you will see:

The dropdown updates the rotational angle transformation applied to page viewports.

Next:

Select "90° Clockwise" for landscape scans turned on their side.

Tip:

180° is useful for documents scanned upside-down via automatic document feeders.

Step 4 of 7 Page Target Selector (#which, #custPages)

Choose Target Pages

What to do:

Select which pages to rotate: "All pages", "Odd pages only", "Even pages only", or "Custom pages".

What you will see:

Choosing "Custom" reveals an input field to specify exact page numbers.

Next:

Select "All pages" to rotate the full document or specify custom numbers.

Tip:

You can target specific landscape inserts (e.g. page 3) without rotating portrait pages.

Step 5 of 7 Rotate Action Button (#goBtn)

Click Rotate PDF

What to do:

Click the primary "Rotate PDF" button.

What you will see:

The client-side engine updates the rotation matrix on the target page dictionaries.

Next:

Wait for the preview confirmation to appear.

Tip:

Because rotation modifies page metadata, the operation executes virtually instantaneously.

Tips & Best Practices

  • Use Preview or a PDF viewer to confirm orientation before sharing.
  • Use custom pages for mixed portrait and landscape scans.

Common Mistakes to Avoid

  • Confusing odd/even page parity with zero-based indexes.
  • Rotating all pages when only scanned pages need correction.

Troubleshooting & FAQ

If custom rotation does nothing, check that page numbers are valid.

If a viewer caches the old display, close and reopen the output.

Frequently Asked Questions

Does rotation change text?

No, it changes page orientation metadata.

Can I rotate by 45 degrees?

No, the controls provide 90-degree increments.
