Tool Overview & Requirements

Add Watermark draws the text you provide across every page using the selected style settings.

Input One PDF and watermark settings
Output A watermarked PDF
Requirements One readable PDF and non-empty watermark text are required. This is an existing document feature, separate from PDFHub’s developer panel.

Step-by-Step Instructions

Follow these essential instructions to achieve optimal results when using Add Watermark:

  1. Upload a PDF and enter the text to stamp.
  2. Choose font size, opacity, color, and angle.
  3. Select Add Watermark.
  4. Review every page for readability and placement before sharing.

Enter Watermark Text

Step 4 of 7 Sliders (#fsize, #opacity, #angle)

Adjust Size, Opacity & Angle

What to do:

Set font size (e.g. 48pt), opacity slider (e.g. 25%), and diagonal angle (e.g. 45°).

What you will see:

Adjusting opacity ensures the watermark is clearly visible without obscuring underlying text.

Next:

Choose an opacity around 20-30% for readable documents.

Tip:

A 45-degree diagonal angle runs across the full body of the page for maximum security.

Tips & Best Practices

  • Use low opacity when the underlying content must remain readable.
  • Test on a copy before applying a mark to an important source.

Common Mistakes to Avoid

  • Using text that covers critical content.
  • Forgetting that the mark is applied to every page.

Troubleshooting & FAQ

If the text is hard to see, increase opacity or choose a contrasting color.

If the output fails, retry with a readable unencrypted PDF.

Frequently Asked Questions

Can I watermark only selected pages?

The current tool applies it to every page.

Does PDFHub add developer branding as a watermark?

No. User-entered watermark text is the only watermark feature.
