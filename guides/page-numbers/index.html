Tool Overview & Requirements

Add Page Numbers embeds a number label on each page with position, format, starting number, font size, and color controls.

Input One PDF
Output A numbered PDF
Requirements One readable PDF is required. The number is drawn onto every page, so leave sufficient margin.

Step-by-Step Instructions

Follow these essential instructions to achieve optimal results when using Add Page Numbers:

  1. Upload a PDF and wait for its page count.
  2. Choose a position, format, starting number, font size, and color.
  3. Select Add Numbers.
  4. Review the first and last pages of the generated PDF.

Tips & Best Practices

  • Use a smaller font on narrow pages.
  • Leave a clear margin at the selected edge.

Common Mistakes to Avoid

  • Choosing white text on a light page.
  • Forgetting that the start number affects every subsequent page.

Troubleshooting & FAQ

If a number overlaps content, choose another position or smaller size.

If the PDF cannot load, repair or export a readable copy first.

Frequently Asked Questions

Can I number selected pages only?
