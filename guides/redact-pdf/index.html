Tool Overview & Requirements

Redact PDF renders pages for marking, then draws black rectangles into the output PDF. Inspect the exported copy carefully before sharing.

Input One PDF and drawn redaction areas
Output A redacted PDF
Requirements One readable PDF is required. Redaction coordinates are based on the rendered page and must cover the complete sensitive area.

Step-by-Step Instructions

Follow these essential instructions to achieve optimal results when using Redact PDF:

  1. Upload a PDF and choose a page.
  2. Drag over every sensitive region to create a black box.
  3. Move through pages and repeat as needed; use Clear Page to start a page again.
  4. Select Save Redacted PDF and verify the result in a separate viewer.

Tips & Best Practices

  • Cover complete lines and nearby identifying context, not just the visible word.
  • Search or select text in the exported PDF to confirm sensitive content is no longer exposed.

Common Mistakes to Avoid

  • Redacting only a screenshot layer or forgetting another page.
  • Sharing the source PDF instead of the redacted output.

Troubleshooting & FAQ

If a box is misplaced, clear that page and redraw.

If text can still be selected outside a box, expand the redaction area and export again.

Frequently Asked Questions

Is redaction reversible?

Treat the exported result as permanent, but retain the source privately.

Does it detect sensitive text automatically?

No, marking is manual.
