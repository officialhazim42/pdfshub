Tool Overview & Requirements

PDF to Excel reads text positions, detects rows and columns, and exports the extracted table data. It works best when the source has selectable, aligned text.

Input A text-based PDF
Output XLSX or CSV
Requirements A text-based PDF works best. Choose pages, a detection mode, and XLSX or CSV output.

Step-by-Step Instructions

Follow these essential instructions to achieve optimal results when using PDF to Excel:

  1. Upload the PDF containing a table or aligned text.
  2. Choose pages, column detection, and output format.
  3. Use Preview Table to inspect the extracted rows.
  4. Select Export to Excel and verify totals and column alignment.

Tips & Best Practices

  • Try Auto first, then Tab/space or Each line if the table structure is unusual.
  • Always compare important totals with the source PDF.

Common Mistakes to Avoid

  • Using a scanned PDF without OCR.
  • Treating visual spacing as guaranteed spreadsheet columns.

Troubleshooting & FAQ

If no data appears, run OCR first or choose a text-based source.

If columns shift, change the detection mode and preview again.

Frequently Asked Questions

Can it extract scanned tables?

Not directly; run OCR first.

Does preview export the file?

No, use Export to Excel.
