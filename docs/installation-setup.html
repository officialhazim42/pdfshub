Installation & Local Development Setup

Prerequisites, repository cloning, local development servers, and environment configuration.

Download 75-Page Manual (PDF) Open PDF in Tab Browse All 33 Tools

System Prerequisites

  • Node.js: Version 18.0.0 or higher.
  • npm: Version 9.0.0 or higher.
  • Modern Browser: Chromium, Firefox, or Safari for Playwright automated testing.

Step-by-Step Setup Instructions

TerminalBash
# 1. Clone repository from GitHub
git clone https://github.com/officialhazim42/pdfshub.git
cd pdfshub

# 2. Install development dependencies
npm install

# 3. Launch local development server
npx serve .
# Or preview with Cloudflare Wrangler
npm run preview

Environment Variables & Secrets

Zero Secrets Architecture: PDFHub has no backend database, no authentication servers, and no private API keys. You do not need an .env file to run or build the complete application locally.
