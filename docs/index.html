Client-Side Browser Execution Model

PDFHub operates as a static, decentralized web utility platform. Unlike legacy PDF converters that upload documents to remote server farms, PDFHub compiles document transformation pipelines into WebAssembly and JavaScript engines that execute directly inside your device's browser memory.

100% Client-Side Privacy Guarantee for 31 of 33 Tools: Documents selected in your browser are read into binary ArrayBuffer memory buffers. They are parsed, modified, and serialized entirely in local RAM. Zero bytes are uploaded to any server.

Data Processing Classification

Category Tools Count Implemented Tools Network & API Behavior
100% Client-Side 31 Tools Merge, Split, Remove, Extract, Organize, Scan, Compress, Repair, JPG to PDF, Word to PDF, PPT to PDF, Excel to PDF, HTML to PDF, PDF to JPG, PDF to Word, PDF to PPT, PDF to Excel, PDF to PDF/A, Rotate, Page Numbers, Watermark, Crop, Edit, Forms, Protect, Unlock, Sign, Redact, Compare, Summarize, PDF to Markdown Zero Network Calls. Files are never uploaded or transmitted off the client device.
CDN Model Assisted 1 Tool OCR PDF (ocr.html) Image processing is performed locally in browser via Tesseract.js WebAssembly worker. On initial run, the worker fetches trained language weights (eng.traineddata.gz) from official CDN. Document images never leave the device.
External API Hybrid 1 Tool Translate PDF (translate.html) Text extraction occurs locally via pdf.js. Selected text chunks (<500 characters) are transmitted via HTTPS to the free public MyMemory Translation API to obtain multi-lingual translated strings.

Browser Storage Usage

PDFHub does not store document content in persistent browser storage. Storage is restricted to lightweight user preferences:

  • pdfhub-theme: Stores user interface color theme ("dark" or "light").
  • pdfhub-favorites: Stores an array of favorited tool IDs locally.
  • pdfhub-recent-history: Stores timestamped log of tool navigation (no document contents or file names are retained).

Supported Formats & Hardware Memory Limits

Because PDFHub performs document manipulations in browser RAM, file capacities are bounded by available system memory and browser tab allocations rather than artificial paywalls.

Operation Input Formats Output Formats Underlying Engine

Office to PDF .docx, .pptx, .xlsx, .xls, .csv Formatted PDF (Browser Print Engine) Mammoth.js, JSZip, SheetJS

Troubleshooting & Frequently Asked Questions

Diagnose common browser memory issues, document encryption restrictions, and layout quirks with these verified solutions.

Universal Troubleshooting Diagnostic Matrix

Symptom / Error Underlying Cause Verified Resolution
Tab crashes or reloads during processing Browser ran out of heap memory on an exceptionally large PDF (>150 MB). Close extraneous browser tabs, or use Split PDF to partition large documents into smaller page batches before applying heavy processing.
PasswordRequired or Decryption Error Document is secured with owner or user encryption. Unlock the document first using the authorized password in Unlock PDF before merging or converting.
Extracted Word / Excel document is blank Source PDF contains scanned raster images rather than selectable vector text. Run the PDF through OCR PDF to extract text characters from images before converting.
Corrupted or truncated PDF stream Damaged cross-reference (xref) table or broken EOF trailer. Run the damaged document through Repair PDF to regenerate the catalog structure.
