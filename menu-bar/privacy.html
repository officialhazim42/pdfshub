Privacy Center

PDFHub is a static browser application. Processing and network behavior can differ by tool, so use this page as a map rather than a blanket promise.

Browser processing

Many PDF tools use browser libraries such as pdf-lib or PDF.js to read and transform files locally. This includes common organization, annotation, image conversion, and extraction workflows.

Network-dependent tools

OCR may load Tesseract language data, Translate PDF calls the MyMemory service, and AI Summarizer may use its configured external AI service. Review those tool pages before processing sensitive content.

Local storage

PDFHub stores theme preferences, favorites, and recent tool links in this browser's localStorage. It does not need an account. Clearing site data removes those application-managed records.
